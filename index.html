大模型应用

元酱 OpsGuard：基于 deepseek-r1:8b 的电商履约与卖家风险巡检 Agent

2025 大模型工程师

项目描述

基于本地 Ollama DeepSeek-R1 构建电商运营巡检 Agent，面向卖家履约异常、物流延迟、低分评价和订单风险巡检场景，实现自然语言查询、风险解释和任务下发闭环。选用 Olist 公开电商数据集构建可复现业务环境，使用 DuckDB 建立订单、卖家、商品、物流和评价分析视图，设计延迟率、低分率、取消率、运费占比等运营风险指标。基于 LangGraph 设计动态路由工作流，区分 SOP 问答、指标查询、巡检任务创建和混合问题，并通过 Pydantic schema、SQLGlot 只读校验和任务工具保证 Agent 调用安全可靠。

主要职责

  • 构建 Olist 电商数据环境：使用 DuckDB 建立订单、卖家、商品、物流和评价分析视图，设计延迟率、低分率、取消率、运费占比等运营风险指标，为 Agent 查询提供结构化数据基础。
  • 设计 SOP 文档处理管线与 Agent 工作流：使用 Docling/PyMuPDF4LLM 将巡检规则和差评处理流程转换为带 metadata 的结构化文档并基于 FTS/BM25 实现可引用检索；基于 LangGraph 设计动态路由工作流，区分 SOP 问答、指标查询、巡检任务创建和混合问题。
  • 构建评估体系与运营工作台：开发 Streamlit 运营工作台，构建评估集统计意图识别准确率、指标工具成功率、SOP 来源命中率和任务创建成功率，确保 Agent 各环节可度量、可复盘。

RAG系统

FabYield Insight：基于本地 DeepSeek-R1 的半导体制程异常知识问答系统

2025 大模型(RAG)工程师

项目描述

基于本地 Ollama DeepSeek-R1 构建半导体制程异常分析与知识问答系统，面向良率/制程工程师的失败样本解释、异常特征定位、SOP 查询和工程排查报告生成场景。选用 UCI SECOM 半导体制造数据集构建可复现制程分析环境，使用 DuckDB 管理 591 个匿名制程变量、通过/失败标签、缺失率和统计分布，并实现样本级 z-score 异常分析。基于 LangGraph 构建问题路由和可信回答工作流，支持概念问答、单样本异常分析、批量失败样本分析和报告生成，并通过 answer_guard 防止匿名特征被错误解释为真实设备根因。

主要职责

  • 构建 SECOM 制程数据分析环境：使用 DuckDB 管理 591 个匿名制程变量与通过/失败标签，实现样本级 z-score 异常分析、缺失率统计和失败样本批量筛选，为 Agent 提供可查询的制程数据基础。
  • 设计文档解析管线与可信 RAG 工作流：使用 Docling/PyMuPDF4LLM 将制程排查 SOP、缺失值处理规范和报告模板转为结构化 Markdown/JSON 并保留章节、页码和表格信息；基于 LangGraph 构建问题路由工作流，通过 answer_guard 防止匿名特征被错误解释为真实设备根因。
  • 构建双层评估体系：统计问题路由准确率、样本分析成功率、SOP 来源命中率、无依据断言率和合理拒答率，用数据验证 RAG 与工具调用的可靠性，确保输出可追溯、不确定性可说明。
