# Personal Website | Jianyu Li

A personal introduction website built with HTML, CSS, and JavaScript. Features a dark tech-themed design with fully responsive layout for mobile, tablet, and desktop.

## Tech Stack

- HTML5
- CSS3 (Flexbox / Grid / Responsive)
- Vanilla JavaScript (Scroll animations / Mobile menu)

## Sections

- **Home** — Name, specialization, profile photo
- **About** — Personal introduction and basic info
- **Education** — M.S. from WUT & EFREI, B.S. from Heilongjiang University of Science and Technology
- **Internship** — Anhui Xinhe Jiasheng Technology, Shenzhen Jueyier Technology
- **Skills** — LLM & AI, Data & Vector Database, Cloud & Deployment, Dev Tools
- **Projects** — Yuanjiang AI Assistant, Semiconductor Document RAG System
- **Contact** — Email / Phone / WeChat / GitHub / Instagram
